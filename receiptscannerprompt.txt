========================================
RECEIPT OCR PROCESSING
========================================

When the user scans/uploads the receipt:

1. Send the receipt image to the Python Flask backend.
2. Use Tesseract OCR to extract all readable text.
3. Use Python to process and clean the OCR result.
4. Identify the following information whenever available:

- Product name
- Product code / item code / SKU
- Barcode number / GTIN if printed
- Brand
- Category
- Quantity
- Unit price
- Total price
- Purchase date
- Store name

Do NOT assume or invent information that is not present on the receipt.

========================================
PRODUCT IDENTIFICATION
========================================

If a product code, SKU or barcode number is detected:

1. Use that number to search the MySQL product database.
2. If an exact match is found, retrieve the corresponding product.
3. If no code is found, use the product name and brand for matching.
4. If no matching product is found, mark it as:
   "Product not found in database"

The system should allow the user to review and correct the detected product name.

Add a "Nutrition Analysis" button.

When clicked, calculate and display the combined nutrition information of all products detected from the receipt.

========================================
EXPIRY DATE TRACKING
========================================

IMPORTANT:

Do NOT assume that the receipt contains an expiry date.

A receipt may contain a product code, SKU or barcode that identifies the product, but the actual expiry date is normally printed on the product/package rather than the billing receipt.

Therefore:

If an expiry date is detected in the receipt:
- Extract it using Tesseract OCR.
- Save it for the corresponding product.
- Display it in the results.

If an expiry date is NOT detected:
- Display "Expiry date not available".
- Provide an "Add Expiry Date" button.
- Allow the user to enter/select the actual expiry date.
- Save the confirmed expiry date in MySQL.

Never generate or guess an expiry date.

========================================
EXPIRY TRACKING
========================================

For every product with a confirmed expiry date:

Calculate:

- Expiry date
- Days remaining
- Expiry status

Use these statuses:

Fresh / Safe
Expiring Soon
Expired

Example:

Product: Amul Milk
Purchase Date: 02/09/2026
Expiry Date: 04/09/2026
Days Remaining: 2 days
Status: Expiring Soon

If the product has already expired:

Status: Expired

If it is approaching expiry:

Status: Expiring Soon
