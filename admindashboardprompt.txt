Create a complete, modern, responsive Admin Dashboard for my project "NutriMatrix".

PROJECT:
NutriMatrix is an AI-powered nutrition and smart grocery platform. It helps users analyze food products, compare estimated prices across grocery platforms, manage their digital pantry, receive expiry notifications, and plan meals.

TECHNOLOGY:
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Python Flask
- Database: MySQL
- Do not use MongoDB.
- Do not require React or Node.js for this dashboard.
- The dashboard should be designed so it can later connect directly to my Flask + MySQL backend.

DESIGN:
Create a premium, clean, professional health-tech/grocery dashboard.
Use the existing NutriMatrix visual identity:
- Green as the primary color
- Orange/yellow as a secondary accent
- White/light background
- Dark green/black text
- Rounded corners
- Subtle shadows
- Clean typography
- Minimal animations
- No excessive gradients
- No 3D cards
- No unnecessary decorative elements
- Responsive on desktop, tablet and mobile

13. MYSQL DATABASE
--------------------------------------------------

Design the database so products and prices are stored separately.

Products table:

products
- id
- product_name
- category
- image
- description
- calories
- protein
- carbohydrates
- fat
- fiber
- sugar
- sodium
- health_benefits
- healthier_alternatives
- created_at
- updated_at

Product prices table:

product_prices
- id
- product_id
- retailer
- price
- updated_at

Users table:

users
- id
- name
- email
- password_hash
- role
- status
- created_at

Use a foreign key from product_prices.product_id to products.id.

Passwords must be securely hashed. Never store plain-text passwords.
